## How to use this directory

The prompts come from [prompts.chat](https://prompts.chat/), whose prompt data is published under CC0. The workflow listings come from [n8n's template catalog](https://n8n.io/workflows/). All linked template pages were available without a template purchase in their source catalogs when compiled. Running a template can still require an account, paid API, subscription, or other external service. Provider descriptions are shortened for browsing; review each linked page before use.

The SQLite database has `resources`, `resources_fts`, and `metadata` tables. Example search: `SELECT r.title, r.url FROM resources_fts f JOIN resources r ON r.id=f.rowid WHERE resources_fts MATCH 'research';`
